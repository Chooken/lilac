# E036: a type declared inside another type

`structure` and `either` declarations live only at the top level of a file. A
type's body holds fields, variants, methods and hooks, not other types:

```lilac
Outer: structure {
    Inner: structure {
        x: @bit8
    }
}
```

```text
error[E036]: `Inner` is a structure declared inside `Outer`
 --> main.lilac:2:5
  |
1 | Outer: structure {
  | ----- inside `Outer`
2 |     Inner: structure {
  |     ^^^^^ types are declared only at the top level
  |
  = help: move `Inner` to the top level of the file, or into a folder namespace
```

The rejected declaration defines nothing, so its uses are unknown names
(`E023`). Declare the type next to its user instead, and group related
types with a folder namespace, which code elsewhere can name by path:

```lilac
Inner: structure {
    x: @bit8
}

Outer: structure {
    inner: Inner
}
```
