# E033: missing platform hook

An executable (`lilac build`) needs all three platform hooks, which the
compiler calls on the program's behalf: `@entry` (runs the program), `@exit`
(ends the process) and `@compiler_print` (writes panic messages). A runtime
library supplies them; mounting `Standard` (`--lib=Standard=<dir>`) brings
`Standard.Runtime`.

```text
error[E033]: the program defines no `@entry`; an executable needs one
  = note: a runtime library supplies `@entry`, `@exit` and `@compiler_print`
  = help: mount `Standard` (`--lib=Standard=<dir>`), or define the hook yourself
```

Bad (built without `Standard` mounted):

```lilac
main: function () nothing {
}
```

Good, with `--lib=Standard=lib/Standard`, or with the hooks defined:

```lilac
@entry: function (count: @bit_native, arguments: ref unknown, environment: ref unknown) nothing {
    main()
}

@exit: function (code: @bit32) nothing {
    // end the process
}

@compiler_print: function (text: @byte_buffer) nothing {
    // write `text` to standard error
}

main: function () nothing {
}
```

`check`, `emit-ir` and `emit-llvm` need no hooks.
