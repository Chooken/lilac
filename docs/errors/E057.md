# E057: unhandled failure

A function declared with `else` outs can fail
(`half: @bit32 else odd: @bit32`). A call of one must be handled where it
happens, in one of three places:

- a guard: `value: T = call else { … }`, whose `else` block must leave;
- a capture `if`: `if call -> value: T { … } else -> why: E { … }`;
- a `loop if`: `loop if call -> value: T { … }`, which ends when the call
  fails.

There is no automatic propagation: to pass a failure on, handle it and
`fail` in a function that can fail itself.

A function that can fail cannot be a value either, and a function type
cannot fail: only a named function can.

Bad:

```lilac
halve: function (n: @bit32) half: @bit32 else odd: @bit32 {
    if n == 0x9 {
        odd = n
        fail
    }
    half = n
}

main: function () nothing {
    half: @bit32 = halve(0x8)
}
```

```text
error[E057]: `halve` can fail, and the failure is not handled
  --> main.lilac:10:20
   |
10 |     half: @bit32 = halve(0x8)
   |                    ^^^^^^^^^^ this call can fail
   |
   = help: handle it where it happens: `value: T = call else { return }`, `if call -> value: T { ... }`, or `loop if call -> value: T { ... }`
```

Good:

```lilac
main: function () nothing {
    half: @bit32 = halve(0x8) else {
        return
    }
}
```
