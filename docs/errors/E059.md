# E059: a guard's `else` block must leave

A guard (`value: T = call else { … }`) binds the call's success outs in
the current scope. When the call fails there are no values to bind, so
its `else` block must not reach its end: it ends in `return`, `fail`,
`break`, `continue`, `@panic` or `@trap` (or an `if` or `match` whose
every branch does). To go on either way, use a capture `if` instead.

Bad:

```lilac
halve: function (n: @bit32) half: @bit32 else odd: @bit32 {
    if n == 0x9 {
        odd = n
        fail
    }
    half = n
}

main: function () nothing {
    misses: @bit32 = 0x0
    half: @bit32 = halve(0x8) else {
        misses = 0x1
    }
}
```

```text
error[E059]: a guard's `else` block must leave
  --> main.lilac:11:36
   |
11 |       half: @bit32 = halve(0x8) else {
   |  ____________________________________^
12 | |         misses = 0x1
13 | |     }
   | |_____^ this block can finish
   |
   = help: end it with `return`, `fail`, `break`, `continue`, `@panic` or `@trap`; the bindings have no value after it
```

Good:

```lilac
main: function () nothing {
    misses: @bit32 = 0x0
    if halve(0x8) -> half: @bit32 {
    } else {
        misses = 0x1
    }
}
```
