# E000: invalid token

The source contains text that is no valid token: a malformed number
literal (`0x` with no digits, a digit the base does not have), a bad escape
(strings allow `\"`, `\\`, `\n` and `\xHH`), a lone `}` in f-string text
(write `}}`), a string, character or f-string literal its line ends inside,
a character literal that does not hold exactly one character, or a
character the language does not use (a lone `$` that does not start an
f-string). Lexing continues after the bad text, and a bad literal is still
read as a literal, so one typo is one error.

Bad:

```lilac
main: function () nothing {
    x: @bit32 = 0b102
}
```

```text
error[E000]: invalid digit `2` in binary literal
 --> main.lilac:2:17
  |
2 |     x: @bit32 = 0b102
  |                 ^^^^^
```

Good: write the literal in a base that has its digits (`0x42`), fix the
escape, close the literal, or remove the stray character.
