# E060: literal value error

A literal's value cannot be represented in its target type, a
fold-required intrinsic (`@size_of`) cannot be evaluated at compile time, or
a constant integer division panics on every run. These are value errors, not
type errors: the type is right, the constant is not.

Cases:

- An integer literal that needs more bits than its target holds: a hex/bin or
  decimal literal wider than its annotated type (`x: @bit8 = 0x1FF`), a value
  past 64 bits (`0x1_0000_0000_0000_0000`), or one that does not fit the
  conversion width of a numeric object (`x: Int8 = 300`).
- A float literal past the target's maximum finite value
  (`x: @fbit16 = 100000.0`).
- `@size_of` on a value that is not a compile-time-constant typed integer.
- A non-finite float literal result, folded at compile time (SPEC §2).
- An integer division or remainder that panics whatever runs before it
  (SPEC §3, Integer division):
  - by a constant zero, whatever the dividend: literal arithmetic
    (`1 / 0`, `1 % 0`), an `@i_div*`/`@i_mod*` intrinsic, a `/` or `%`
    whose `=>` hook receives a constant zero (`value / 0x0 as Int32`), or
    a global's initializer;
  - a signed `@i_div_W` or `@i_mod_W` of the constant minimum value by a
    constant `-1`, whose quotient does not fit.

  At run time these are the panics `division by zero` and `division
  overflow`. The compile-time error fires in every function, called or not
  (the note lists every caller), but never in an arm a constant condition
  rules out.

Bad (overflowing literal):

```lilac
main: function () nothing {
    x: @bit8 = 0x1FF
}
```

```text
error[E060]: value needs 9 bits but @bit8 holds 8
  --> main.lilac:2:16
   |
 2 |     x: @bit8 = 0x1FF
   |                ^^^^^ literal overflows
```

Bad (division by zero):

```lilac
main: function () nothing {
    x: @bit8 = 1 / 0
}
```

```text
error[E060]: division by zero
  --> main.lilac:2:16
   |
 2 |     x: @bit8 = 1 / 0
   |                ^^^^^ the divisor is zero
```

A remainder by zero is the same `E060`, with the same message.

Bad (division overflow):

```lilac
half: function () value: @bit8 {
    value = @i_div_8(0x80, 0xFF)
}
```

```text
error[E060]: division overflow
  --> main.lilac:2:13
   |
 2 |     value = @i_div_8(0x80, 0xFF)
   |             ^^^^^^^^^^^^^^^^^^^^ the minimum signed value divided by -1 does not fit
   |
   = note: reached from:
             at half (main.lilac:2:13)
```

Good (integer and float literals in range, a division guarded by a
constant condition):

```lilac
main: function () nothing {
    x: @bit8 = 0xFF
    y: @bit64 = 0x1_0000_0000
    z: @fbit32 = 3.14
    if 0x0 {
        w: @bit8 = @i_div_u_8(x, 0x0)
    }
}
```
