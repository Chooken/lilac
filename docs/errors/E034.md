# E034: platform hook defined twice

A program has one of each platform hook (`@entry`, `@exit`,
`@compiler_print`). Hooks are unit-global, so a second definition anywhere
in the program, including in a mounted library, is an error. This usually
means two runtime libraries are mounted, or the program defines a hook that
`Standard.Runtime` already supplies.

```text
error[E034]: `@exit` is defined more than once in the program
 --> main.lilac:4:1
  |
1 |    @exit: function (code: @bit32) nothing {
  |  __-
2 | |  }
  | |__- first defined here
3 |
4 |    @exit: function (code: @bit32) nothing {
  |   _^
5 |  | }
  |  |_^ defined again here
  |
  = note: a program has one of each platform hook; mount at most one runtime library
```

Bad (with `Standard` mounted):

```lilac
@exit: function (code: @bit32) nothing {
}
```

Good: leave the hooks to `Standard`, or do not mount it and define all
three yourself.
