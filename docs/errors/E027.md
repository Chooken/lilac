# E027: return slot never assigned

A named return slot with no assignment on any path through the body. `return`
takes no arguments, so every slot must be written before it.

Bad:

```lilac
get: function () result: @bit32 {
}
```

```text
error[E027]: return slot `result` is never assigned
  --> main.lilac:1:23
   |
 1 | get: function () result: @bit32 {
   |                       ^^^^^^^ assign it before `return`
```

Good:

```lilac
get: function () result: @bit32 {
    result = 0x1
}
```
