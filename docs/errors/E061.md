# E061: too many format pieces

An f-string lowers to a fixed-capacity `@format_args` table. The table
holds at most 16 pieces, so a single f-string can have at most 16 literal
chunks and holes combined. Split longer strings into two f-strings (or
`@byte_buffer` slices) instead.

Bad (17 pieces):

```lilac
main: function () nothing {
    name: @byte_buffer = "x"
    x: @format_args = $"{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}{name}"
}
```

```text
error[E061]: too many format pieces (max 16)
  --> main.lilac:3:23
   |
 3 |     x: @format_args = $"{name}...{name}"
   |                       ^^^^^^^^^^^^^^^^^ too many pieces here
```

Good (16 pieces or fewer):

```lilac
main: function () nothing {
    name: @byte_buffer = "x"
    x: @format_args = $"hello {name}"
}
```
