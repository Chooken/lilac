# E029: ambiguous import

A name is exported by two namespaces the same file `using`s and is referenced
unqualified. It is reported only on use: an unreferenced collision is not an
error. The reference and each competing declaration are labelled.

A local name — or one reached from an ancestor namespace — shadows an imported
one, so no ambiguity arises there. `using` is per file and non-transitive, so
only the imports in the referencing file participate.

Bad:

```lilac
// main.lilac
using util1
using util2

main: function () nothing {
    foo()
}
```

```lilac
// util1/one.lilac
foo: function () nothing {
}
```

```lilac
// util2/two.lilac
foo: function () nothing {
}
```

```text
error[E029]: `foo` is ambiguous
  --> main.lilac:5:5
   |
 5 |     foo()
   |     ^^^
   = ambiguous reference here
  --> one.lilac:1:1
   |
 1 | foo: function () nothing {
   | ^^^^^^^^^^^^^^^^^^^^^^^^^^ candidate from here
  --> two.lilac:1:1
   |
 1 | foo: function () nothing {
   | ^^^^^^^^^^^^^^^^^^^^^^^^^^ candidate from here
```

Good: rename one export, import only one of the namespaces, or declare a local
`foo` (a local binding shadows both imports).
