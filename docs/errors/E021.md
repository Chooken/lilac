# E021: unresolved name

A value name that is neither a local, an item, nor an intrinsic. Using a
hook, an intrinsic or a type where a value belongs is also `E021` (a
function is a value as `ref f`, `E077`), as is an unknown member
(`value.nope`, `Type.nope`).

Bad:

```lilac
main: function () nothing {
    x: @bit8 = nope
}
```

```text
error[E021]: unresolved name `nope`
  --> main.lilac:2:15
   |
 2 |     x: @bit8 = nope
   |               ^^^^ not a local or item
```

Good: bind it first or fix the spelling; check `using` imports when the
name lives in another folder.

Inside a type's bodies its constants and static functions are bare names,
but its fields and methods are not: they are read through `self`, and the
error says so.

```lilac
Box: object {
    value: @bit8

    get: function (self) @bit8 => value
}
```

```text
error[E021]: unresolved name `value`
  --> main.lilac:4:35
   |
 4 |     get: function (self) @bit8 => value
   |                                   ^^^^^ not a local or item
   |
   = help: `value` is a field of `Box`: write `self.value`
```

A constant of a generic type is one value for every instance, so its
initializer cannot call the type's static functions, which belong to each
instance: `FIRST: @bit32 => start()` in `List[T]` is `E021`.
