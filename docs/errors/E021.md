# E021: unresolved name

A value name that is neither a local, an item, nor an intrinsic. Using a
function or a type where a value belongs is also `E021`. (M4 refines unknown
member access to `E040`.)

Bad:

```lilac
main: function () nothing {
    x: @bit8 = nope
}
```

```text
error[E021]: unresolved name `nope`
  --> main.lilac:2:15
   |
 2 |     x: @bit8 = nope
   |               ^^^^ not a local or item
```

Good: bind it first or fix the spelling; check `using` imports when the
name lives in another folder.
