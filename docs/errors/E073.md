# E073: an f-string with no formatter type

An f-string is an `@format_args(W)`, and its `W` (the type its holes are
formatted into) comes from where it goes, the way a number literal's width
does:

1. an expected `@format_args(W)`, or an alias of one, gives `W`;
2. any other expected type takes the `W` of its one `@conversion` from an
   `@format_args(W)`, and the f-string converts through it;
3. with nothing expected (a statement, an operand) there is no `W`.

So an f-string where nothing is expected is `E073`, and so is one whose
expected type converts from two formats (from two formatter types).

Bad:

```lilac
main: function () nothing {
    $"hello"
}
```

```text
error[E073]: an f-string needs a type here
 --> main.lilac:2:5
  |
2 |     $"hello"
  |     ^^^^^^^^ nothing says what this formats into
  |
  = help: use it where an `@format_args(W)` (or a type that converts from one) is expected, or give it one with `as`
```

Good (pass it where a format is expected, or declare it):

```lilac
Out: structure {}

main: function () nothing {
    text: @format_args(Out) = $"hello"
}
```

When the expected type converts from two formats, pick one with `as`:
`$"..." as Format`.
