# E039: a top-level condition is not constant

A top-level `if` or `match` chooses which declarations exist, so its
condition (or scrutinee) must be a constant expression (SPEC "Constant
conditions"): inline constants, `=>` functions with constant arguments,
and `@builtin` facts.

```lilac
match @builtin.Target.os {
    .Windows {
        using Platform.Windows as Host
    }
} else {
    using Platform.Posix as Host
}
```

A condition that reads a global or calls an ordinary function is an error:

```lilac
enabled: @bit8 = 0x1

if enabled {
    feature: function () nothing {}
}
```

```text
error[E039]: a top-level condition must be constant
 --> main.lilac:3:4
  |
3 | if enabled {
  |    ^^^^^^^ not a constant expression
```

Use an inline constant (`enabled: @bit8 => 0x1`) instead.

A condition may name an item another top-level `if` or `match` declares;
it is decided once that one is. When checking the condition fails in code
it calls rather than in the condition itself, this error is reported with
a note, and the failure is reported where that code is used.
