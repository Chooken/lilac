# E026: private member

An `object` member declared inside a `private { … }` block is inaccessible from
outside its owning object. The member is found but gated: the error points at the
access and at the declaration. Fields, instance and static functions, and nested
members are all gated the same way, and nested `private` blocks flatten.

A namespace-private item is different: `private` at file top level excludes an
item from `using`, so an importer sees an *unresolved* name (`E021`), not
`E026`.

Bad:

```lilac
Object: object {
    member: @bit8

    private {
        secret: function (instance: ref Object) result: @bit8 {
            result = instance.member
        }
    }
}

main: function () nothing {
    variable: Object = Object {
        member = 0x1
    }

    value: @bit8 = variable.secret()
}
```

```text
error[E026]: `secret` is a private member
  --> main.lilac:16:20
   |
16 |     value: @bit8 = variable.secret()
   |                    ^^^^^^^^^^^^^^^
   = accessed from outside its object
  --> main.lilac:5:9
   |
 5 |         secret: function (instance: ref Object) result: @bit8 {
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ declared private here
```

Good (call it from the object's own member bodies, or make it public):

```lilac
Object: object {
    member: @bit8

    secret: function (instance: ref Object) result: @bit8 {
        result = instance.member
    }
}

main: function () nothing {
    variable: Object = Object {
        member = 0x1
    }

    value: @bit8 = variable.secret()
}
```
