# E053: a type contains itself by value

A structure field (or either payload) stores its value inline, so a type that
contains itself by value, directly or through other types, would be infinitely
large. Store the recursive part behind a `ref` instead.

Bad:

```lilac
Node: structure {
    value: @bit32
    next: Node
}
```

```text
error[E053]: `Node` contains itself by value
  --> main.lilac:3:11
   |
 3 |     next: Node
   |           ^^^^
   = this field would make the type infinitely large
help: store it behind a `ref` instead
```

Good:

```lilac
Node: structure {
    value: @bit32
    next: ref Node
}
```
