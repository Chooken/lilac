# E063: use of an empty place

A place (a variable, a parameter, an out, or a field of one) is either
full or empty. Reading a value whose type cannot be copied moves it, and
`@move(x)` moves any value: the place is empty after. An out starts empty
until it is set. Reading an empty place, or one that is empty on some
path (moved in one branch, or in an earlier iteration of a loop), is
`E063`; so is setting a field of an empty place, since the rest of it
holds no value.

A type copies when it has its own `@on_copy`, or when it has no
`@on_drop` of its own and every field copies. Otherwise it moves. When
the move that emptied the place was implicit, the error says which type
stopped it from copying: the moved type itself, or a type it holds.

Bad:

```lilac
Handle: structure {
    id: @bit32

    @on_drop: function (self) nothing {
    }
}

take: function (handle: Handle) nothing {
}

main: function () nothing {
    handle: Handle = Handle { id = 0x1 }
    take(handle)
    take(handle)
}
```

```text
error[E063]: `handle` is used after it was moved
  --> main.lilac:14:10
   |
13 |     take(handle)
   |          ------ moved here: `Handle` cannot be copied
14 |     take(handle)
   |          ^^^^^^ used here while empty
   |
   = note: `Handle` has an `@on_drop` and no `@on_copy`, so a use by value moves it
   = help: to keep using `handle`, pass a `ref` to it where it moved, or give `Handle` an `@on_copy` so it copies
```

Good: lend it instead, or set the place again before reading it. (Once
a `ref` to `handle` is taken, it moves only by `@move`: `E079`.)

```lilac
lend: function (handle: ref Handle) nothing {
}

main: function () nothing {
    handle: Handle = Handle { id = 0x1 }
    lend(ref handle)
    lend(ref handle)
    other: Handle = Handle { id = 0x2 }
    take(other)
    other = Handle { id = 0x3 }
    take(other)
}
```

Or give `Handle` an `@on_copy`, so each use copies it.
