# E072: a format or scoped value where it cannot live

A format (`@format_args(W)`) borrows twice: each hole points at a value,
and the hole pointers sit in the frame of the function that built it. A
`scoped structure` (a view) borrows what it points at. So only locals and
parameters hold either, and outs and other scoped structures' fields hold
a scoped structure.

For a format:

- a field, an either payload, an array element, an out, a global or a
  constant cannot be a format (a `ref` to one can);
- a format cannot be stored through a `ref`, or with `@write`: the target
  may outlive the call;
- a format whose hole borrows a temporary (a call result, a literal) cannot
  be assigned to an existing local, or be an arm of a value `if` or
  `match`: the temporary ends with the statement, and the local does not.

A format that initializes a new local keeps its temporaries alive as long
as the local, so declaring one is the usual fix.

For a scoped structure: a field of an ordinary structure, an either
payload, an array element, a global, a constant, or a generic type's slot
cannot be one, and it cannot be stored through a `ref` or with `@write`.
Keep what it views instead, and build the view where it is used, or make
the holder a `scoped structure` too.

Bad:

```lilac
Out: structure {}

@format: function (value: ref @bit32, out: ref Out) nothing {}

Message: structure {
    text: @format_args(Out)
}

count: function () value: @bit32 {
    value = 0x1
}

main: function () nothing {
    first: @bit32 = 0x0
    text: @format_args(Out) = $"{first}"
    text = $"{count()}"
}
```

```text
error[E072]: a format cannot be a field
 --> main.lilac:6:5
  |
6 |     text: @format_args(Out)
  |     ^^^^^^^^^^^^^^^^^^^^^^^ `@format_args(Out)` here
  |
  = note: a format borrows its holes, so only locals and parameters hold one
  = help: to keep the text, format it into a value that owns it, such as a `String`

error[E072]: this format borrows a temporary that ends with the statement
  --> main.lilac:16:5
   |
16 |     text = $"{count()}"
   |     ^^^^^^^^^^^^^^^^^^^ the local outlives the statement
   |
   = help: declare a new local for it: `name: Format = $"..."`
```

Good (format into a value that owns the text, or declare a new local):

```lilac
Out: structure {}

@format: function (value: ref @bit32, out: ref Out) nothing {}

count: function () value: @bit32 {
    value = 0x1
}

main: function () nothing {
    text: @format_args(Out) = $"{count()}"
}
```
