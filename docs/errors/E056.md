# E056: invalid declaration shorthand

`variable: Type.function(args)` is short for
`variable: Type = Type.function(args)`. `function` must be a static
function of `Type`: a function in `Type`'s body that does not take `self`.
It must return exactly one `Type`, since the shorthand names the variable's
type once. The segment before `(` is always the function, so
`variable: A.B.make(args)` calls `make` on the type `A.B`, and a namespace
there (`variable: Os.allocate(size)`) is not a type.

A type is not callable: `Type(args)` and the `@init` hook are gone. Name
the constructor instead (`new`, `with_capacity`, …) and call it.

Bad:

```lilac
Pair: object {
    a: @bit32
    b: @bit32

    first: function (pair: ref Pair) value: @bit32 {
        value = pair.a
    }
}

main: function () nothing {
    other: Pair { a = 0x1, b = 0x2 }
    p: Pair.first(ref other)
}
```

```text
error[E056]: `Pair.first` returns `@bit32`, not one `Pair`
  --> main.lilac:12:13
   |
12 |     p: Pair.first(ref other)
   |             ^^^^^ must return exactly one `Pair`
   |
   = help: the shorthand needs a function that makes a `Pair`; otherwise write `variable: Pair = ...`
```

Good:

```lilac
Pair: object {
    a: @bit32
    b: @bit32

    new: function (a: @bit32) value: Pair {
        value = Pair { a = a, b = 0x2 }
    }
}

main: function () nothing {
    p: Pair.new(0x1)
}
```
