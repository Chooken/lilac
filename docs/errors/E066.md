# E066: invalid `@discard`

`@discard(value)` ends a value's life without its `@on_drop`: the
fields become places of their own, so the function can move out what
it needs, and the rest drop one by one at the end of the scope. Only
the type's own functions may do that, so for every other caller
`@on_drop` is a guarantee. It is an error when:

- the value is not owned by the function: it is behind a `ref`, a
  global, or a temporary;
- the function is not declared in the value's type;
- the value is not a structure (an either has no fields to keep);
- the value is discarded on some paths only, so where the paths join
  its `@on_drop` would run on some and not on others.

Bad:

```lilac
Handle: structure {
    id: @bit32

    @on_drop: function (self) nothing {
    }
}

leak: function (handle: Handle) nothing {
    @discard(handle)
}
```

```text
error[E066]: `@discard` of a `Handle` outside `Handle`
 --> main.lilac:9:14
  |
9 |     @discard(handle)
  |              ^^^^^^ a `Handle`
  |
  = help: only a function declared in `Handle` may end one without its `@on_drop`
```

Good: the type offers the operation itself, taking the value by value.

```lilac
Handle: structure {
    id: @bit32

    @on_drop: function (self) nothing {
    }

    into_id: function (self: Handle) id: @bit32 {
        @discard(self)
        id = self.id
    }
}
```
