# E024: ambiguous literal or width

A number literal (or a width-taking intrinsic like `@truncate`) with no
bit-typed expected type to take its meaning from. Literals are
compiler-known bytes; the expected type is the anchor.

Bad:

```lilac
main: function () nothing {
    0x1
}
```

```text
error[E024]: number literal needs an expected bit type
  --> main.lilac:2:5
   |
 2 |     0x1
   |     ^^^ annotate the binding
```

Good:

```lilac
main: function () nothing {
    x: @bit8 = 0x1
}
```
