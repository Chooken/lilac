# E041: signature mismatch (reserved)

**Reserved in M4.** `E041` is not emitted: a call whose arguments do not
match a member's declared signature reports `E022` (arity/shape); the same
failure inside a generic instantiation is re-attributed to the use site under
[`E042`](E042.md) with a signature detail label. The code is reserved for the
dedicated signature diagnostic in a later milestone; until then nothing in the
compiler produces it.

Bad (`get` takes no arguments, one is supplied):

```lilac
Object: object {
    get: function () result: @bit32 {
        result = 0x1
    }
}

main: function () nothing {
    x: @bit32 = Object.get(0x1)
}
```

```text
error[E022]: wrong number of arguments: expected 0, found 1
  --> main.lilac:9:21
   |
 9 |     x: @bit32 = Object.get(0x1)
   |                 ^^^^^^^^^^^^^^^ arity mismatch here
```

Good (call it the way the object declares it): `Object.get()`.
