# E044: wrong number of generic arguments

A generic declaration must be applied with exactly as many explicit type
arguments as it declares generic parameters. Too few, too many, or any
argument on a non-generic type reports `E044`; the bogus application is
never interned. Arity is checked before the applied type is built, so a
mismatch can never become a real `Instance`.

Bad (one parameter, two arguments):

```lilac
GenObj[T]: structure {
    value: T
}

main: function () nothing {
    x: GenObj[@bit8, @bit16] = GenObj {
        value = 0x0
    }
}
```

```text
error[E044]: wrong number of generic arguments for `GenObj`
  --> main.lilac:6:8
   |
 1 | GenObj[T]: structure {
   | ^^^^^^^^^^^^^^^^^ declared with `[T]`
 6 |     x: GenObj[@bit8, @bit16] {
   |        ^^^^^^^^^^^^^^^^^^^^^ expected 1 generic argument, found 2
```

Good:

```lilac
main: function () nothing {
    x: GenObj[@bit8] = GenObj {
        value = 0x0
    }
}
```

A generic function's value is one instance too, and its arguments are
never inferred: `ref id` of a generic `id` is `E044`, with the help to
write them (`ref id[@bit32]`), and so is `ref G[@bit8]` of a global or
`ref Box[@bit8].make[@bit8]` of a function that takes none.
