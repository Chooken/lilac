# E042: unsatisfied generic requirements

A generic declaration is checked once per concrete `(declaration, type
arguments)` instance. When the specialized body uses an operation the
concrete type cannot support (a missing member, an incompatible signature, a
failed conversion), the failure is re-attributed to the **use site**: one
`E042` lists every failed requirement, with the generic's definition and the
instantiation chain as notes. Nothing from the generic's innards leaks as a
separate error, so one bad instantiation is exactly one diagnostic.

The primary label is always the call site ("instantiated here"). Each
captured body failure becomes a secondary label at the operation that failed,
the definition is a note, and each active instantiation frame is a note
prefixed `in instantiation of `. Frames past five are elided unless
`--verbose`. Identical failures (same declaration, arguments, and call site)
are deduplicated.

Helps are emitted where the compiler can justify them: edit-distance
did-you-mean over the concrete type's members, argument arity counts,
`ref`-vs-value hints, and a discovered `@conversion`. The **`using` help is
downgraded**: v1 `using` is a single-file stub with no module table to
consult, so the compiler cannot resolve an external member and emits no
`using` suggestion (ruling R9).

Bad:

```lilac
gen_function[T]: function () out: T {
    out = T.other()
}

main: function () nothing {
    variable: @bit32 = gen_function[@bit32]()
}
```

```text
error[E042]: type `@bit32` does not satisfy `gen_function[T]` requirements
  --> main.lilac:6:24
   |
 6 |     variable: @bit32 = gen_function[@bit32]()
   |                        ^^^^^^^^^^^^^^^^^^^^^^ instantiated here
note: main.lilac:1:1 required by `gen_function[T]` here
note: main.lilac:2:11 missing method `other` on `@bit32`
note: in instantiation of gen_function__1__bit32
```

Good (instantiate with a type that provides the member):

```lilac
Object: object {
    other: function () result: @bit32 {
        result = 0x1
    }
}

gen_function[T]: function () out: T {
    out = T.other()
}

main: function () nothing {
    variable: @bit32 = gen_function[Object]()
}
```
