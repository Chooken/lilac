# E043: missing conversion

No single `@conversion(from → to)` bridges the value to the expected type.
Conversions apply left-to-right only after an exact match fails, take exactly
one step (no chains), and for binary operators anchor on the left: only the
right side converts toward the left. `==` never converts.

Bad (no binding in scope):

```lilac
main: function () nothing {
    a: @bit32 = 0x1
    b: @bit8 = a
}
```

```text
error[E043]: no conversion from @bit32 to @bit8
  --> main.lilac:3:15
   |
 3 |     b: @bit8 = a
   |               ^ conversion attempted here
```

Good (declare the one step):

```lilac
@conversion: function (from: @bit32) to: @bit8 {
    to = @truncate(from)
}

main: function () nothing {
    a: @bit32 = 0x1
    b: @bit8 = a
}
```
