# E010: mismatched types

The value's type is not the expected type, and no single `@conversion`
bridges them (Task 5 widens some of these into `E043`). Both sides print
every time. `==` never converts: it needs identical types.

Bad:

```lilac
main: function () nothing {
    y: @bit32 = 0x1
    x: @bit8 = y
}
```

```text
error[E010]: mismatched types: expected @bit8, found @bit32
  --> main.lilac:3:15
   |
 3 |     x: @bit8 = y
   |               ^ found `@bit32` here
   |
   = expected `@bit8` here
```

Good:

```lilac
@conversion: function (from: @bit32) to: @bit8 {
    to = @truncate(from)
}

main: function () nothing {
    y: @bit32 = 0x1
    x: @bit8 = y
}
```
