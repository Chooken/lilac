# E010: mismatched types

The value's type is not the expected type and the position allows no
conversion (`==` never converts; `ref` shapes never convert). Both sides
print every time. A plain type mismatch with a `@conversion` in reach
reports `E043` instead.

A function reference (`ref function (…) …`) is never dereferenced: `ref` of
one is a double reference, `@read`, `@write` and `@drop` of one have no
value to act on, and it casts only to and from `ref unknown` (another
function type, or Lilac to C, is `E010`). `ref value.method` is `E010`
too: there are no bound methods, so write `ref Type.method` and pass the
receiver as the first argument.

A reference capture (`-> v: ref P`) names the payload's own type, and
points into the matched value, so that value must be in memory: matching
a temporary (`match make() { .Some -> v: ref P … }`) is `E010`, since the
temporary is gone when the arm ends. Bind it to a local and match the
local. In a generic body this is decided per instance: a `ref T` capture
of a temporary is fine when `T` is itself a reference (the capture then
copies it), and `E042` names the instance where it is not.

Bad:

```lilac
main: function () nothing {
    a: @bit8 = 0x1
    b: @bit32 = 0x2
    c: @bit8 = a == b
}
```

```text
error[E010]: mismatched types: `==` needs identical types, found @bit8 and @bit32
  --> main.lilac:4:21
   |
 4 |     c: @bit8 = a == b
   |                     ^
   = right side `@bit32` here
  --> main.lilac:4:16
   |
 4 |     c: @bit8 = a == b
   |                ^ left side `@bit8` here
```

Both sides also print for an argument that misses a required `ref` (the
expected annotation and the found value are always labeled):

```lilac
set: function (r: ref @bit8) nothing {
}

main: function () nothing {
    v: @bit8 = 0x1
    set(v)
}
```

```text
error[E010]: mismatched types: expected ref @bit8, found @bit8
  --> main.lilac:6:9
   |
 6 |     set(v)
   |         ^
   = found `@bit8` here
  --> main.lilac:6:5
   |
 6 |     set(v)
   |     ^^^^^^ expected `ref @bit8` here
```

Good (compare identical widths):

```lilac
main: function () nothing {
    a: @bit8 = 0x1
    b: @bit8 = 0x2
    c: @bit8 = a == b
}
```

An `as` cast reports the same ref mismatch; only the `ref unknown` exception
avoids it (`ref T as T` is still `E010`):

```lilac
main: function (p: ref @bit8) nothing {
    q: ref @bit16 = p as ref @bit16
}
```

```text
error[E010]: mismatched types: expected ref @bit16, found ref @bit8
  --> main.lilac:2:21
   |
 2 |     q: ref @bit16 = p as ref @bit16
   |                     ^
   = found `ref @bit8` here
  --> main.lilac:2:26
   |
 2 |     q: ref @bit16 = p as ref @bit16
   |                          ^^^^^^^^^^ expected `ref @bit16` here
```
