# E052: generic hook

Hook bindings (`@add`, `@conversion`, `@on_drop`, …) must be concrete: no
generic parameters, no unsubstituted generic parameter in the signature.
Overloads stay distinct by listing each concrete signature. Hooks declared
inside a generic body are fine — they register once per concrete
instantiation in M4.

Bad:

```lilac
@add[T]: function (lhs: T, rhs: T) result: T {
    result = lhs
}
```

```text
error[E052]: hook bindings must be concrete; generic hooks are rejected
  --> main.lilac:1:1
   |
 1 | @add[T]: function (lhs: T, rhs: T) result: T {
   | ^^^^^^^ generic parameters here
```

Good (one binding per width):

```lilac
@add: function (lhs: @bit8, rhs: @bit8) result: @bit8 => @iadd(lhs, rhs)
```
