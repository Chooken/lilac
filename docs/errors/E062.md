# E062: capture mismatch

Captures bind the outs of a call that can fail by position, under any
names: `-> a: A, b: B` takes the success outs and `else -> e: E` the
failure outs. A guard's bindings take the success outs the same way.
Binding fewer outs than the call has is fine (the rest drop); binding
more is an error.

Only a call that can fail has captures: captures on any other condition,
or a guard on a call that cannot fail, are errors too.

Bad:

```lilac
halve: function (n: @bit32) half: @bit32 else odd: @bit32 {
    if n == 0x9 {
        odd = n
        fail
    }
    half = n
}

main: function () nothing {
    if halve(0x8) -> half: @bit32, rest: @bit32 {
    }
}
```

```text
error[E062]: `halve` has 1 success out, but 2 are bound
  --> main.lilac:10:36
   |
10 |     if halve(0x8) -> half: @bit32, rest: @bit32 {
   |        ----------                  ^^^^^^^^^^^^ no out for this binding
   |        |
   |        this call
```

Good:

```lilac
main: function () nothing {
    if halve(0x8) -> half: @bit32 {
    }
}
```
