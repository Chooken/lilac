# E064: cannot move out of this place

Only a place this function owns can be moved out of: a local, a
by-value parameter, or a field of one. A value that cannot be copied
cannot be read out of memory behind a `ref` (a reference does not own
what it points at), out of a global, or out of a field of a temporary
(the rest of the temporary would still drop). A field also cannot move
out of a type with its own `@on_drop`, which needs every field when it
runs. A `match` capture that would move a payload follows the same
rules.

Bad:

```lilac
Handle: object {
    id: @bit32

    @on_drop: function (self) nothing {
    }
}

Holder: object {
    handle: Handle
}

take: function (holder: ref Holder) handle: Handle {
    handle = holder.handle
}
```

```text
error[E064]: cannot move `Handle` out of a reference
  --> main.lilac:13:14
   |
13 |     handle = holder.handle
   |              ^^^^^^^^^^^^^ `Handle` cannot be copied, so this moves it
   |
   = note: a `ref` does not own what it points at
   = help: take a `ref` to it instead, or move the value its owner holds
```

Good: take the owner by value, so the field can move out of it.

```lilac
take: function (holder: Holder) handle: Handle {
    handle = holder.handle
}
```
