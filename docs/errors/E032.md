# E032: no entry point

`lilac build` produces an executable, so the program needs an entry point: a
non-`extern` `main` function in the root namespace. A `main` inside another
namespace (`A.main`) is an ordinary function and does not count.

```text
error[E032]: no `main` function; `lilac build` needs an entry point
  = help: add `main: function () nothing { … }`, or use `lilac check` for a library
```

Bad:

```lilac
// lib.lilac
helper: function () nothing {
}
```

Good:

```lilac
main: function () nothing {
    helper()
}

helper: function () nothing {
}
```

Only `build` requires `main`. `check`, `emit-ir` and `emit-llvm` accept a
library without one.
