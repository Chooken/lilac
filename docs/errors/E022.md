# E022: wrong arity or shape

A call with the wrong number of arguments, a call on something that is not
a function, a value taken from a call that returns `nothing`, a statement
that drops returned values, a malformed `@conversion` shape (which needs
exactly one parameter and one return), or a `break` or `continue` outside a
`loop`.

Bad:

```lilac
get: function () result: @bit32 {
    result = 0x1
}

main: function () nothing {
    x: @bit8 = get(0x1)
}
```

```text
error[E022]: wrong number of arguments: expected 0, found 1
  --> main.lilac:6:15
   |
 6 |     x: @bit8 = get(0x1)
   |               ^^^^^^^^ arity mismatch here
```

Good: pass exactly what the signature declares.
