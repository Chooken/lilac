# E022: wrong arity or shape

A call with the wrong number of arguments, a call on something that is not
a function (a value whose type is not a `ref function`), a value taken
from a call that returns `nothing`, more bindings than the call returns
(`a, b, c = two()`), a malformed `@conversion` shape (which needs exactly
one parameter and one return), or a `break` or `continue` outside a
`loop`.

Dropping values is not an error: `f()` as a statement drops all of its
results, `a: T = f()` binds the first and drops the rest, and a statement
like `5 + 5` is only faded in the editor.

Bad:

```lilac
get: function () result: @bit32 {
    result = 0x1
}

main: function () nothing {
    x: @bit8 = get(0x1)
}
```

```text
error[E022]: wrong number of arguments: expected 0, found 1
  --> main.lilac:6:15
   |
 6 |     x: @bit8 = get(0x1)
   |               ^^^^^^^^ arity mismatch here
```

Good: pass exactly what the signature declares.
