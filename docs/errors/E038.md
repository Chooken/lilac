# E038: a global's initializer is not constant

A global variable (`name: Type = value` at the top level, or as a static
member of a type) is set before the program starts, so its initializer
must be a constant expression (SPEC "Constant conditions"): literals,
inline (`=>`) constants and functions, `@builtin` facts, `@size_of`, and
object or variant literals of those, and addresses (below). A call to an
ordinary function, a string, or another global's value is not constant.

```lilac
start: function () value: @bit32 { value = 0x5 }

counter: @bit32 = start()
```

```text
error[E038]: a global's initializer must be constant
 --> main.lilac:3:19
  |
3 | counter: @bit32 = start()
  |                   ^^^^^^^ not a constant expression
```

Leave the global zeroed (`counter: @bit32`) and assign it at run time,
or make the initializer constant (`start: function () @bit32 => 0x5`).

An initializer may hold addresses: `ref f` (a function's) and `ref other`
(another global's), also cast to another `ref` type. They are filled in
when the program is linked, so nothing may compute with one: comparing
two, testing one, or reading one as a number is not constant.

```lilac
first: function () nothing {}

address: @bit_native = @ptr_to_address(ref first as ref unknown)
```

```text
error[E038]: a global's initializer must be constant
 --> main.lilac:3:24
  |
3 | address: @bit_native = @ptr_to_address(ref first as ref unknown)
  |                        ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ not a constant expression
```
