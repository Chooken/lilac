# E058: `fail` outside a function that can fail

`fail` leaves a function through its failure outs, so only a function
declared with `else` outs can use it. Set the failure outs, then `fail`;
`return` (or the end of the body) is the success side. A function with no
failure outs to set writes `else nothing`.

Bad:

```lilac
first: function (count: @bit32) value: @bit32 {
    if count == 0x0 {
        fail
    }
    value = count
}
```

```text
error[E058]: `fail` outside a function that can fail
 --> main.lilac:3:9
  |
3 |         fail
  |         ^^^^ this function cannot fail
  |
  = help: declare failure outs after `else` in the signature: `function (...) value: T else error: E` (or `else nothing`)
```

Good:

```lilac
first: function (count: @bit32) value: @bit32 else nothing {
    if count == 0x0 {
        fail
    }
    value = count
}
```
