# E065: an out is not set

An out starts empty, and the compiler never invents a value for it.
Every success out (before `else` in the signature) is set on every path
that returns: at each `return` and at the end of the body. Every
failure out (after `else`) is set at each `fail`. A path that ends in
`@panic`, `@trap` or a `@compile_error` sets nothing.

Bad:

```lilac
first_even: function (a: @bit32, b: @bit32) even: @bit32 {
    if @bit_and_32(a, 0x1) == 0x0 {
        even = a
    } else if @bit_and_32(b, 0x1) == 0x0 {
        even = b
    }
}
```

```text
error[E065]: `even` may not be set when the function returns
 --> main.lilac:7:1
  |
7 | }
  | ^ returns here with `even` not set on every path
  |
  = help: set every success out before the function returns: an out starts empty
```

Good: set it on every path, or make the function able to fail.

```lilac
first_even: function (a: @bit32, b: @bit32) even: @bit32 else nothing {
    if @bit_and_32(a, 0x1) == 0x0 {
        even = a
    } else if @bit_and_32(b, 0x1) == 0x0 {
        even = b
    } else {
        fail
    }
}
```
