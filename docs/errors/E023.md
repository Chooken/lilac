# E023: unknown type

A type name that is neither a builtin (`@bit8`, `@byte_buffer`, `unknown`,
…) nor a declared `object`/`enum`/`union` in scope. `unknown` itself only
lives behind a reference.

Bad:

```lilac
main: function () nothing {
    x: Nope = 0x1
}
```

```text
error[E023]: unknown type `Nope`
  --> main.lilac:2:8
   |
 2 |     x: Nope = 0x1
   |        ^^^^ no such type in scope
```

Good:

```lilac
main: function () nothing {
    x: @bit32 = 0x1
}
```
