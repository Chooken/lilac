# E037: a constant array index out of bounds

An `@array_at` index that is known at compile time must be less than the
array's length. An index computed at run time is checked when it runs and
panics with `index out of bounds`; a constant one is checked here instead,
so the mistake never waits for a run:

```lilac
first: function (values: ref @array(@bit32, 4)) value: @bit32 {
    value = @array_at(values, 0x4)
}
```

```text
error[E037]: index 4 is out of bounds for an array of length 4
 --> main.lilac:2:31
  |
2 |     value = @array_at(values, 0x4)
  |                               ^^^ the last index is 3
  |
  = note: reached from:
            at first (main.lilac:2:31)
              at main (main.lilac:9:17)
```

The check covers every function, including ones nothing calls yet, and
the note lists every call that reaches it. Indexes start at `0x0`, so the
last element of an `@array(T, N)` is `N - 1`.

An access inside an arm that a constant condition rules out is not checked,
since that arm is never compiled:

```lilac
if @i_greater_than_u_native(@array_len(values), 0x4) {
    fifth: @bit32 = @array_at(values, 0x4)
}
```
