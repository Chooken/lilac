# E040: unknown member

A member access or method call names a member the object type does not
declare. The diagnostic points at the member name, names the member and the
owner, and suggests the closest declared member by edit distance. This is the
M4 refinement of the M2-era `E021` lookup miss; until that refinement is
wired the same failure still reports `E021`.

Bad:

```lilac
Object: object {
    member: @bit8
    get: function () result: @bit8 {
        result = 0x1
    }
}

main: function () nothing {
    variable: Object = Object {
        member = 0x1
    }
    value: @bit8 = variable.gett()
}
```

```text
error[E040]: no member `gett` on `Object`
  --> main.lilac:11:20
   |
11 |     value: @bit8 = variable.gett()
   |                    ^^^^^^^^^^^^^^^ unknown member
   |
help: `Object` has `get`, did you mean `get`?
```

Good (spell the member the object declares):

```lilac
main: function () nothing {
    variable: Object = Object {
        member = 0x1
    }
    value: @bit8 = variable.get()
}
```
