# E040: unknown member (reserved)

**Reserved in M4.** `E040` is not emitted: a member lookup that fails
anywhere reports `E021`, and the same failure inside a generic instantiation
is re-attributed to the use site under [`E042`](E042.md) with a
"missing method/member ..." label. The code is reserved for the dedicated
member-lookup diagnostic in a later milestone; until then nothing in the
compiler produces it.

Bad (fails to find `gett` on `Object`):

```lilac
Object: object {
    member: @bit8
    get: function () result: @bit8 {
        result = 0x1
    }
}

main: function () nothing {
    variable: Object = Object {
        member = 0x1
    }
    value: @bit8 = variable.gett()
}
```

```text
error[E021]: no member `gett` on `Object`
  --> main.lilac:12:20
   |
12 |     value: @bit8 = variable.gett()
   |                    ^^^^^^^^^^^^^
   = no such member
```

Good (spell the member the object declares): use `variable.get()`.
