# E054: alias collides with a declaration

`using A.B as Name` binds the namespace `A.B` to `Name` in the file that
contains the directive. The alias may shadow a namespace, or a name the file
reaches from an ancestor namespace or imports through another `using`, but
it may not share its name with an item of the file's own namespace (in any of
the folder's files, `private` ones included). Two aliases of one name in a
file are also `E054`; one namespace may be aliased under several names.

A local or parameter named like an alias shadows it inside its block, as it
shadows items.

Bad:

```lilac
// main.lilac
using geometry as Math

main: function () nothing {
}
```

```lilac
// math.lilac (same folder)
Math: object {
    value: @bit32
}
```

```text
error[E054]: alias `Math` collides with a declaration of the same name
 --> main.lilac:1:19
  |
1 | using geometry as Math
  |                   ^^^^ alias declared here
  |
 ::: math.lilac:1:1
  |
1 | Math: object {
  | ---- `Math` declared here
  |
  = help: an alias may shadow a namespace, but not a declaration in its own namespace; rename one of them
```

Good: rename the alias (`using geometry as Geo`) or the declaration.
