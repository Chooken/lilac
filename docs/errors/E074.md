# E074: an alias refers to itself

A type alias is another name for a type, so the type it names must not
need the alias to be known: an alias that names itself, directly or
through other aliases, names no type at all.

Bad:

```lilac
Pair: alias Both[Pair]
```

```text
error[E074]: alias `Pair` refers to itself
  --> main.lilac:1:18
   |
 1 | Pair: alias Both[Pair]
   |                  ^^^^ `Pair` is needed to know what `Pair` names
```

Two aliases that name each other are reported once, at the alias that
closes the loop, with a note giving the chain (`First` → `Second` →
`First`).

Good: give the recursive type a name of its own, a structure, and store
the recursive part behind a `ref` (`E053`):

```lilac
Pair: structure {
    value: @bit32
    next: ref Pair
}
```
