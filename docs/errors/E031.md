# E031: live `@compile_error` reached

A `@compile_error("message")` call is reachable: its function is reachable
from `main` or an `--export` root (through a direct call or a taken function
address), and the call is not in the dead arm of a constant condition. So
compilation stops with the author's message.

Dead `@compile_error` calls vanish silently:

- those in the dead arm of an `if`, `and`/`or` or `match` whose condition is a
  *constant expression* (a literal, `@size_of`, an inline `=>` constant such as
  `Standard.true`, or `=>` calls and integer intrinsics over those), and
- those in functions nothing reachable calls (an uncalled function or an
  unused hook).

```text
error[E031]: boom
  --> main.lilac:6:24
   |
 6 |         @compile_error("boom")
   |         ---------------^^^^^^-
   |         |              |
   |         |              message here
   |         evaluated here
   |
   = note: reached from:
             at check (main.lilac:6:9)
             at main (main.lilac:11:5)
```

The note is the call chain that keeps the call alive: one shortest path from
a root, innermost first, in the same form as a `@panic` stack trace. Generic
functions show their instance (`Holder[@bit32].make`), compiler-generated
drop/copy glue is hidden (a hook reached through a drop shows the function
that drops the value, at the scope's closing `}`, the `return` or `break`
leaving it, or the statement whose temporary it was), and a frame that only takes the next function's
address, rather than calling it, is marked `[address taken]`.

Delete the code that keeps the call alive, or guard it with a constant
condition that is false. A local is never a constant expression, even one
initialized from a constant:

```lilac
t: Bool = false
if t {
    @compile_error("reported: `t` is a local")
}
if false {
    @compile_error("silent: `false` is an inline constant")
}
```

A value of a type with an `@on_drop` or `@on_copy` hook is never a constant
expression either. See SPEC "Constant conditions and `@compile_error`" for the
full list.
