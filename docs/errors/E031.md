# E031: live `@compile_error` reached

A `@compile_error("message")` call survived constant folding: its branch
is reachable with a constant condition, so compilation stops with the
author's message. Dead `@compile_error` calls (in branches proven
unreachable by constant conditions) vanish silently — only live ones
report.

```text
error[E031]: boom
  --> main.lilac:6:9
   |
 6 |         @compile_error("boom")
   |         ^^^^^^^^^^^^^^^^^^^^^^ live `@compile_error` here
```

Move the call behind a non-constant condition, or delete the branch that
keeps it alive.
