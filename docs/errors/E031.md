# E031: live `@compile_error` reached

A `@compile_error("message")` call survived constant folding and global
dead-code elimination: its function is reachable from `main` (through a
direct call or a taken function address), so compilation stops with the
author's message. Dead `@compile_error` calls vanish silently — both those
in branches proven unreachable by constant conditions and those in
functions nothing reachable calls (an uncalled function or an unused hook).
Only live ones report.

```text
error[E031]: boom
  --> main.lilac:6:9
   |
 6 |         @compile_error("boom")
   |         ^^^^^^^^^^^^^^^^^^^^^^ live `@compile_error` here
```

Move the call behind a non-constant condition, or delete the code that
keeps it alive.
